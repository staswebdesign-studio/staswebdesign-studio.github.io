# Репозиторий демо студии «Триада»

Общие правила студии: репозиторий `staswebdesign-studio/knowledge`, файл AGENTS.md (раздел «Демо» обязателен).
Если правила расходятся, правы они. Пишем по-русски.

## Устройство
- Каждое демо в своей папке: `<папка>/index.html`, `<папка>/politika.html`, `<папка>/img/*.webp`.
  Адрес: https://staswebdesign-studio.github.io/<папка>/ (позже demo.triada-agency.ru/<папка>).
- Лендинг: главная и политика. Многостраничный: столько страниц, сколько нужно, все в папке компании.
- Демо создаётся один раз. Дальше только правки в той же папке. Чужие папки не трогаем.
- В main напрямую не пишем. Работа в ветке `claude/demo-<папка>`: после пуша GitHub сам вливает её в main,
  публикует сайт и удаляет временные ветки (`.github/workflows/publish.yml`).
- Фото компании из 2ГИС сервер кладёт в ветку `photos/<папка>`, папка `<папка>/_2gis/`. Берём оттуда только лучшие,
  копируем в `<папка>/img/`, саму `_2gis` не коммитим.

## Обязательно в каждой странице
- `<meta name="robots" content="noindex, nofollow">`, `<meta name="viewport" content="width=device-width, initial-scale=1">`.
- Один файл стилей и один скрипт на демо (или внутри страниц). Без счётчиков, аналитики и чужих скриптов.
- Картинки только WebP и только используемые. Unsplash подключаем ссылкой на images.unsplash.com.
- Нигде не пишем «демо» и «концепт», кроме функций, которые работают только на настоящем сайте
  (оплата, заказы, кабинет): там мягко пишем, что это демонстрация, и даём сбросить её.
